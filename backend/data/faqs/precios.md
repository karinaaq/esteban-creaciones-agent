# Precios orientativos

Los precios varian segun complejidad, materiales y cantidad. Las carpetas creativas
parten de un rango accesible para disenos simples. Los centros de mesa dependen
del tamano, la cantidad y la tematica. Los disfraces dependen del talle, materiales
y nivel de detalle.

No hay un presupuesto minimo rigido. Pedidos muy chicos se evaluan caso a caso.
Encargos con varias piezas suelen ser mas convenientes.

La cotizacion se confirma despues de entender la idea: que se necesita, para cuando,
diseno y materiales. Este indice documental orienta; no reemplaza una cotizacion final.
