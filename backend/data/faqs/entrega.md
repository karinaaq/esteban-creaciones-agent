# Entrega y zona

La zona principal de atencion es local o cercanias; el barrio o ciudad se acuerda
al momento del pedido. Envios a otras localidades se evaluan segun tamano del
pedido y costo de transporte.

El retiro coordinado es la opcion mas habitual. Se avisa cuando el trabajo esta
listo y se acuerda dia y horario.

Para pedidos grandes o lejos se puede coordinar envio. El costo de envio no esta
incluido en la cotizacion del trabajo creativo salvo que se indique lo contrario.

Si cambia la fecha del evento, conviene avisar lo antes posible. Si hay cupo en
la nueva fecha se reprograma. Si el trabajo ya esta avanzado puede haber ajuste
de costo o de alcance.
