# Brand assets (Esteban Creaciones)

Place files here (opaque / non-transparent backgrounds are fine):

| File | Usage |
|------|--------|
| `logo.png` | White chip + amber border in the header |
| `banner.jpg` | Welcome hero (navy/orange CSS overlay) |

Other formats (`.webp`, `.jpeg`) work if you update `LOGO_SRC` / `BANNER_SRC` in `src/App.tsx`.

No transparent PNG required — CSS frames and overlays the assets.
